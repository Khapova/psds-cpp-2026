# Найти все элементы

Необходимо реализовать функцию `FindAll`, которая принимает на вход контейнер
`std::vector<int>` и указатель на функцию-предикат, а возвращает контейнер 
позиций всех элементов, удовлетворяющих предикату, в порядке возрастания. 

## Примечание

- Запрещено использовать функции из `<algorithm>`
