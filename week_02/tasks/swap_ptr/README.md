# Обмен указателей

Необходимо написать функцию `SwapPtr`, которая меняет местами два указателя
на тип `int`, а также указатели на указатель на тип `int`. Сами объекты, 
на которые указывают указатели, изменяться **НЕ** должны.

## Ограничения

- Нельзя использовать `std::swap` из стандартной библиотеки
